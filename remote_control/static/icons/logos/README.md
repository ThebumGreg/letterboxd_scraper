# App logos

These SVGs come from [Simple Icons](https://simpleicons.org) (v13.21.0) and are released under CC0 1.0 (see
`LICENSE-simple-icons.md`). The logos themselves are trademarks of their owners and are used here only to label
buttons for those services. Disney+, Hulu, Peacock and a few others are not in the set, so they get an initials
badge in the brand colour. To use a real icon instead, drop `<package or app id>.png` (or `.svg`/`.webp`) into
`remote_control/static/icons/` and reload the page; it takes priority over everything here.
