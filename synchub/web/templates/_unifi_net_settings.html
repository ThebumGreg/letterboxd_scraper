UniFi Network (Wi-Fi presence)

Lets the TV dashboard see that a phone has left or joined the home Wi-Fi: "Left for school" in the morning and "Welcome home" when someone arrives. Set the people up on the TV dashboard tab. It only asks which devices are connected, never where anyone is. The Network application has its own key (made on its Settings, Control Plane, Integrations page); a Protect key does not work here.

The console's own address, without https://. This is usually the same console as Protect.
