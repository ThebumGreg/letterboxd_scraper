Cleanup

When a worker replaces a file with a converted one, it keeps the original for a while: renamed next to the new file on the share (.synchub-original, which Radarr, Sonarr and Jellyfin ignore), or on the worker PC when the share cannot rename. Restore puts the original back under its old name (the converted file is set aside for 7 days, not deleted); Keep longer pushes back the date it is removed; Delete now frees the space.
