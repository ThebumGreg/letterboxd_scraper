Settings

The Library pass queues a few files at a time, never while someone is watching in Jellyfin. A worker reads only the sampled parts of each film. The damage check pass reads every byte of a file with ffmpeg and counts decode errors, so it is slow and heavy on the share; it never runs while someone is watching in Jellyfin.
