Database backups

Every night at 03:30 SyncHub saves a consistent copy of its database (settings, profiles, decisions, everything) in the backups folder beside it, and keeps the newest few. A copy is also saved before an upgrade changes the database. Tools has a button to do it now.

0 turns the nightly copy off.

Live updates

Radarr and Sonarr tell SyncHub the moment something is grabbed or imported (a webhook), and SyncHub checks download progress while anything is downloading.

Checked this often only while something is downloading (otherwise every 5 minutes at most). 0 turns it off; anything from 1 to 9 is treated as 10.
Not "localhost", which would mean Radarr's own machine. For example http://192.168.1.50:5001, or http://synchub:5001 on a shared Docker network. Saved with the form below.
Everything Jellyfin's Webhook plugin sends is stored so it can be used later. Older events are deleted once a day. 0 keeps them for ever (playback progress is stored at most every 30 seconds per player, so growth is slow).
