Look at a share

A worker lists the video files, looks at the ones it has not seen (or that changed) and reports what it found. Files already looked at are skipped, so running it again is quick.

Folders to leave out
One per line: a folder name or wildcard (Extras, *Sample*) or share:folder/path. The default is for this scan only; change it for good under Settings below.
Settings
Used for every file unless you pick another when approving it. Profiles are listed below.
A worker deletes the source only after checking the library copy is still whole and the source is unchanged. You can keep any file's source on its page. Switching this off stops pending deletions.
Sonarr cannot forget a single episode without deleting its file, so for TV “stop tracking” means “stop monitoring”. A rename inside a share always passes on the new location. Set each share's Radarr and Sonarr path on the Storage page.
A new destination or folder name changes which files count as already in place.
