Options

The global choices for the library: where files go, when a film is compressed, preview clips, the default conversion profile and what happens to the source. Looking at the queue and approving files stays on the Library tab.

Library settings
A movie over the limit is re-encoded to HEVC with a bitrate cap so it ends under the target, never padded up to it. Removing unwanted tracks is tried first. HDR10 and HLG are kept. TV episodes have their own switch below.
Limits are per hour of runtime, so a 22-minute and a 90-minute episode are judged alike. Around 2 to 3 GB per hour of 1080p HEVC looks clean; typical 1080p web downloads are 3 to 5 GB per hour.
Preview clips before compressing
A worker cuts a short window, compresses it exactly as the real job would and makes the matching original; you watch both side by side. The clips are removed after {{ preview_keep_days }} days. This applies to new Radarr/Sonarr downloads; for a file already in the Library, press Preview on its page.
Used for every file unless you pick another when approving it. Profiles are listed below.
A worker deletes the source only after checking the library copy is still whole and the source is unchanged. You can keep any file's source on its page. Switching this off stops pending deletions.
Sonarr cannot forget a single episode without deleting its file, so for TV “stop tracking” means “stop monitoring”. A rename inside a share always passes on the new location. Set each share's Radarr and Sonarr path on the Storage page.
A new destination or folder name changes which files count as already in place.
Conversion profiles

A profile says how a file is converted: the video codec and quality, and what happens to subtitles. Choose one per file when you approve it, or set the default under Settings. The built-in profiles cannot be changed; make your own below.
