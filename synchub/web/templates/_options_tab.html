Options

The global choices for the library: where files go, when a film is compressed, preview clips, the default conversion profile and what happens to the source. Looking at the queue and approving files stays on the Library tab.

Library settings
A film is re-encoded to HEVC 10-bit, down to the ceiling for its picture size (the video bitrate, so a short and a long film are judged alike). It is only touched when it is more than the trigger times the ceiling, so files that are already efficient are left alone. Removing unwanted tracks comes first, and HDR10 and HLG are kept. Every conversion profile can use its own numbers; these are the defaults they follow.
The GB limits catch a huge file whose bitrate looks fine; 0 turns one off.
Names and audio
Show folders for files brought in get the year SyncHub knows for the show (Show (2018)) in the Jellyfin style. Folders already in the library are never renamed for this.
A compatible track is E-AC-3 5.1 (AAC stereo for stereo sources), placed first and set as the default, so players that cannot decode TrueHD or DTS-HD pick it. Jellyfin does not choose a track by codec. A conversion profile can change any of these.
Extra copies and Dolby Vision 7 (default for every profile)
The copy keeps HDR10 when the film is HDR and never goes bigger than the original. A conversion profile can turn the extra copy on or off and change these values.
Preview clips before compressing
A worker cuts a short window, compresses it exactly as the real job would and makes the matching original; you watch both side by side. The clips are removed after {{ preview_keep_days }} days. This applies to new Radarr/Sonarr downloads; for a file already in the Library, press Preview on its page.
Used for every file unless you pick another when approving it. Profiles are listed below.
A worker deletes the source only after checking the library copy is still whole and the source is unchanged. You can keep any file's source on its page. Switching this off stops pending deletions.
Sonarr cannot forget a single episode without deleting its file, so for TV “stop tracking” means “stop monitoring”. A rename inside a share always passes on the new location. Set each share's Radarr and Sonarr path on the Storage page.
A new destination or folder name changes which files count as already in place.
